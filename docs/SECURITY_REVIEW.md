## Findings fixed in this phase

1. **High (privacy): incomplete account erasure.** The purge left code, drafts, notes, attempts and
   replays, XP and billing links. Fixed and covered by a schema-driven test.
2. **High (dependencies):** `mysql2` (plaintext auth downgrade) and `deepmerge-ts` (stack exhaustion),
   both via the Prisma CLI. Pinned to patched versions; `dompurify` (low, via Monaco) too.
3. **Low:** export lacked practice progress and the review queue. Added.
4. **Low (hygiene):** CI workflow carried secret-shaped test values. CI now generates them per run.
5. **Tooling:** the Playwright config loaded `NODE_ENV=development` from the local `.env`, which
   broke `next build` when e2e ran against a production build locally. It no longer leaks.

No high or critical findings are open.

# Runbook: rotate keys and secrets

Rotate on a schedule (yearly), when someone with access leaves, or immediately when a secret may
have leaked. Edit `/etc/forge/forge.env` (and `/etc/forge/runner.env` on runners), then redeploy:
`sudo infra/production/scripts/deploy.sh $(cat /var/lib/forge/current)`.

| Secret                                            | How                                                                                                                                                            | User impact                                                                                                                                |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `RUNNER_JOB_SIGNING_KEYS`, `RUNNER_CALLBACK_KEYS` | Prepend a new `kN:secret` (newest signs, all verify). Deploy API **and** runners. After 15 min remove the old key, deploy both again.                          | None                                                                                                                                       |
| `APP_SECRET`                                      | Sessions, CSRF, flags and unsubscribe links are HMACs of it. Replace and deploy.                                                                               | Everyone is signed out; old unsubscribe links stop working; **per-user flags change** (solved challenges stay solved). Only on compromise. |
| `ENCRYPTION_KEY`                                  | Encrypts TOTP secrets. There is no in-place re-encryption yet: rotating means admins re-enrol 2FA. Only on compromise.                                         | Admins re-enrol TOTP                                                                                                                       |
| `POSTGRES_PASSWORD`                               | `dc exec postgres psql -U forge -c "ALTER USER forge PASSWORD '<new>'"`, update the env file, deploy.                                                          | Seconds of errors                                                                                                                          |
| `RUNNER_REDIS_*_PASSWORD`                         | Update env files, `runner-redis-acl.sh`, `dc restart runner-redis`, deploy, update runners.                                                                    | Queued jobs retry                                                                                                                          |
| `STRIPE_SECRET_KEY`                               | Roll in the Stripe dashboard (it keeps the old key valid for a period you choose), update, deploy.                                                             | None                                                                                                                                       |
| `STRIPE_WEBHOOK_SECRET`                           | Roll the endpoint secret in Stripe, update, deploy quickly (Stripe retries failures for 3 days).                                                               | None                                                                                                                                       |
| `SMTP_URL`, OAuth client secrets                  | Create the new credential at the provider, update, deploy, revoke the old one.                                                                                 | None                                                                                                                                       |
| `METRICS_TOKEN`                                   | Replace, deploy, update the scraper.                                                                                                                           | None                                                                                                                                       |
| Backup GPG key                                    | New keypair on your machine, new public key to `/etc/forge/backup-public.asc`. **Keep the old private key** until the last backup made with it is 30 days old. | None                                                                                                                                       |
| GHCR pull token, SSH keys                         | Revoke and re-issue at GitHub / on the VMs.                                                                                                                    | None                                                                                                                                       |

After any rotation caused by a leak: check `AuditLog` for admin actions in the window, and note
the incident in `docs/SECURITY_REVIEW.md`.

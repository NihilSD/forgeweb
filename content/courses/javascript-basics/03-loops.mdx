A classic `for` loop counts:

```js
for (let k = 1; k <= 5; k++) {
  console.log(k);
}
```

`%` gives the remainder, so `k % 3 === 0` means "k is a multiple of 3". Use `===` (strict equality) in JavaScript. When several conditions can be true at once, check the most specific first.

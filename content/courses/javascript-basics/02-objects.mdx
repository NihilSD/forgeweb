An object maps **keys** to **values**:

```js
const stock = {};
stock['lamp'] = 3;
stock.chair = 5;
// stock is { lamp: 3, chair: 5 }
```

`'a b c'.split(' ')` returns `['a', 'b', 'c']`. Careful: `''.split(' ')` returns `['']`, a single empty string.

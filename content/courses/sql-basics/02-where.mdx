`WHERE` keeps only rows for which a condition is true. Combine conditions with `AND` and `OR`:

```sql
SELECT name FROM products WHERE category = 'books' AND stock > 0;
```

Text values go in single quotes. `<` excludes the boundary, `<=` includes it.

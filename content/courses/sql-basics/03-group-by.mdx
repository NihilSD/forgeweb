Aggregate functions summarise many rows: `COUNT(*)`, `SUM(col)`, `AVG(col)`, `MIN`, `MAX`.

`GROUP BY` makes one group per distinct value and applies the aggregate to each:

```sql
SELECT category, COUNT(*) AS n
FROM products
GROUP BY category;
```

`AS n` names the output column.

Many problems ask "have I seen a matching value before?". Checking every earlier element is O(n²). A **hash map** (Python `dict`, JavaScript `Map`) answers in O(1) on average, so one pass is enough:

```python
seen = {}
for j, x in enumerate(values):
    if target - x in seen:
        return [seen[target - x], j]
    seen[x] = j
```

**Recognise it:** pairs, duplicates, counting, "complement" lookups.

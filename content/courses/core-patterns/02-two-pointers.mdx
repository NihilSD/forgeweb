On a **sorted** array, put one pointer at each end. If the pair's sum is too small, move the left pointer right; if too big, move the right pointer left. Each step discards one element for good, so the whole search is O(n).

```visualizer
two-pointers
```

**Recognise it:** sorted input, pairs, "closest to", palindromes, merging.

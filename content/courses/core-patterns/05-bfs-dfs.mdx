Grids and networks are **graphs**. Depth-first search (a stack or recursion) goes deep before backtracking; it is good for "is it reachable?" and exploring everything. **Breadth-first search** (a queue) visits nodes in order of distance, so on unweighted graphs the first time it reaches the goal is along a shortest path.

```visualizer
graph-search
```

**Recognise it:** shortest steps, levels, connected regions, spreading processes.

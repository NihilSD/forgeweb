The **{{app}}** habit tracker stores one value per day: `True` if the user practised that day,
`False` if not. `longest_streak(days)` returns the length of the longest run of consecutive
practice days.

Return 0 when there are no practice days (or no days at all).

Users who are on their best streak right now see a smaller number. The function has **one bug**.

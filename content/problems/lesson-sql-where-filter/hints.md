## 1. Nudge

Two conditions must both be true.

## 2. Approach

Use WHERE with AND: `stock > 0 AND price < 20`.

## 3. Pseudocode

SELECT name FROM products WHERE stock > 0 AND price < 20 ORDER BY name

## 4. Solution

```sql
SELECT name FROM products WHERE stock > 0 AND price < 20 ORDER BY name;
```
